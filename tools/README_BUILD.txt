VIALUMIX - COMPILATION LOCALE

1. Installer Java 17.
2. Double-cliquer sur RUN_AFTER_BUILD.bat.
3. Le script utilise Gradle Wrapper et telecharge automatiquement Gradle/dependances si necessaire.
4. Le JAR final est copie dans %APPDATA%\.minecraft\mods.
5. Les DLL DLSS fournies sont copiees dans %APPDATA%\.minecraft\vialumix.
6. Lancer Minecraft Fabric 1.20.1 avec Sodium 0.5.13 + Iris 1.7.6.

Important : le backend natif Vialumix/MCVR n'est pas encore le renderer RT final. Le JAR actuel est une base executable de l'integration Java/UI/loader.
